# PageFX — Testing Guide

## Automated Tests

```bash
npm run build -- --no-bump
npm test
```

114 tests cover every version 1 defect fixed in 2.0.0, the split party (the reported bug, including splits made by other Mods), page geometry on snap-1, snap-2 and hex pages, even spreading of spawns, the per-page spawn cap, taking over version 1 tokens (GM Notes, bars as text, interdiction), every command and menu, presets (shared custom FX), triggers (rounds, a "Round" entry, turns, enter and leave, once-only, `checkToken`), the public API and the handouts, against a stubbed Roll20 API. The stub behaves as Jumpgate was seen to behave (see `DEVELOPERS.md`). It cannot check what is drawn, so run the live checks below before release.

## Live Tests

Live tests use the Playwright harness (`P:/Code/Dnd-Roll20/playwright-tests`, PlaywrightHarness Mod installed in the game) in **Mod Test Lab - PageFX** (22181951), a copy of Mod Test Lab: Jumpgate, sandbox v1.5, with the Open Grid and Docks pages and the player account Test Player.

The spec is `playwright-tests/tests/pagefx/pagefx.spec.ts`. Run it against the copy with its own browser profiles:

### Checklist

- [x] Install `PageFX.js`; the console shows `-=> PageFX v2.0.0 … <=-` and the GM gets "PageFX is ready."
- [x] The Journal has **PageFX - Help** and **PageFX - Command Deck**, neither visible to players; every Command Deck button works.
- [x] Select a token and apply a preset: the effect runs on the ribbon page.
- [x] Move one player to another page on their own: that page's effects run and the player sees them; the ribbon page keeps its own.
- [x] Bring the party back: the split page's effects stop.
- [x] Every button on an effect card: Built-in FX (type and colour prompts), Saved FX, Custom JSON (drawn in colour), Timing, Area, Intensity, Rename, Add layer, Remove layer.
- [x] Off, Pause, Pause all and Resume all from the menu and the Command Deck.
- [x] A no-effect area: nothing spawns inside it.
- [x] Drag a player token into an area with an enter trigger: the effect starts or fires.
- [x] Advance the Turn Tracker past its last entry: a round trigger starts the effect.
- [x] Change the language: the menus and both handouts follow.
- [x] Version 1 upgrade: install 1.3, set up tokens named PageFX and NullFX the version 1 way, then install 2.0.0. They keep working.
- [x] Each preset by eye on a 70 px page and on a scaled page.
- [x] The core checks in a Legacy game.
