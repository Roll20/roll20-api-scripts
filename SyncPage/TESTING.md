# SyncPage — Testing Guide

## Automated Tests

```bash
npm run build -- --no-bump
npm test
```

These cover every 0.1.9 defect fixed in 1.0.0, all six object types, pairing (exact, moved tokens, leftovers), the echo guard, per-page properties and page settings, excluded layers, every delete mode with the recycle bin and Undo, both hide modes (turn order kept, marketplace fall-back), repair (drift, missing copies, source deletes, objects made while not watching), pause and resume, repair on start, players and layouts, settings (choices, lists, group overrides, One-Click options), button expiry, migration from 0.1.9, the public API and the handouts, against a stubbed Roll20 API. The stub behaves as Jumpgate was seen to behave (see `DEVELOPERS.md`). It cannot check rendering, the client's own saves or real player views, so run the live checks below before release.

## Live Tests

Live tests use the Playwright harness (`P:/Code/Dnd-Roll20/playwright-tests`, PlaywrightHarness Mod installed in the game) in **Mod Test Lab - SyncPage** (22183020), a copy of Mod Test Lab: Jumpgate, D&D 2024 sheet, sandbox v1.5. The sync group **Lab Room** has the source **Copy of Walls Lab** (a Duplicate Page copy of Walls Lab: walls of every kind, a door, a window, a Legacy path wall, text, five tokens), **SP-Blank** (a blank page SyncPage copied everything onto) and **Copy of Copy of Walls Lab** (made with Duplicate Page and paired).

### Checklist

- [ ] Install `SyncPage.js`; the console shows `-=> SyncPage v1.0.0 … <=-` and the GM gets "SyncPage is ready."
- [ ] The Journal has **SyncPage - Help** and **SyncPage - Command Deck**, neither visible to players; every Command Deck button works.
- [ ] **Make a group from this page**, then **Add this page to a group** on a blank page: everything is copied, page settings too.
- [ ] Duplicate Page, then add the copy: every object is paired, nothing new is made.
- [ ] Drag a token on either page: it moves on every page.
- [ ] Toggle a door in the UI: it changes on every page, and does not flip back.
- [ ] Draw a rectangle (Jumpgate drawing) on a copy: it appears on the source.
- [ ] Select a token on a copy and **Hide here**: a player split onto that page cannot see it; the source is unchanged.
- [ ] Delete a token: it goes everywhere; **Undo** brings every copy back.
- [ ] Deletes with **Ask**: the card's **Delete everywhere** and **Undo** both work.
- [ ] **Players**: move the player, **Everyone to**, **Restore layout**; the show/hide grid hides one page's copy.
- [ ] Settings card: a drop-down setting, a list setting (+/−) and a group override with **Use global**.
- [ ] **Pause**, move a copy, **Resume**: the difference is reported and **Repair now** puts it back.
- [ ] Restart the sandbox: copies keep their IDs and drift is repaired quietly.
